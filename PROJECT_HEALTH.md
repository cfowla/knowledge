# LiteratureAtoms Project Health

Assess:

1. Schema pressure
2. Validation reliability
3. Provenance integrity
4. Extraction consistency
5. ATOM ↔ SEA consistency
6. Source-type coverage
7. Atom-kind coverage
8. Repeated manual work
9. Corpus organization
10. Documentation drift
11. Test coverage
12. Performance/scalability signals

For each finding classify:

OBSERVATION
WATCH
ISSUE
URGENT

Only ISSUE or URGENT findings should normally become GitHub Issues.

Before creating an issue:
- search existing open issues
- avoid duplicates
- cite repository evidence
- define acceptance criteria
- state why the change is warranted now
