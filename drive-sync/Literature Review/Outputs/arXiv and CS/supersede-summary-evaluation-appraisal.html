One-page synthesis

Core thesis. The paper argues that LLM agents have a distinct memory-update or supersession failure: when facts change across sessions, bounded self-maintained memory often preserves stale values or drops current values, even when the same model can answer correctly from full context. The proposed fix is not simply a larger model or a larger memory, but a trainable memory policy optimized directly for temporal fact-currency.

What the source contributes

It isolates the performance gap between full-context reading and bounded-memory maintenance on real conversational update questions, then turns the failure into a verifiable RL environment called Supersede.

Most important result

On LongMemEval knowledge-update oracle questions, gpt-5.4 is reported to fall from 92% full-context accuracy to 77% bounded-memory accuracy, with paired McNemar p = 0.0033. A smaller model also shows a significant gap.

Scale/budget finding

In a 25-question scale study, extending history from about 2 sessions to about 48 sessions drops gpt-4.1-mini from 68% to 28%; proportional memory growth does not recover accuracy in that sample.

Training finding

GRPO fine-tuning of Qwen2.5-3B on synthetic bounded-memory episodes raises held-out LongMemEval oracle accuracy from 9.0% to 16.7%, a relative gain of 86% but still low absolute performance.

Why it matters

The no-re-feed setup mirrors a real design tension in production memory systems: agents cannot keep replaying all prior sessions forever, so memory-write/update policies must decide which facts survive.

Main caveat

The diagnosis is more convincing than the training result. The strongest training claim rests on one small model, one run, synthetic training episodes, and n = 78 held-out questions.

Section-by-section condensation

Abstract

The abstract defines the core problem: long-session agents must answer using the current value of facts that have changed, not values that have been superseded. On LongMemEval knowledge-update questions, replacing full context with bounded, self-maintained memory lowers reported accuracy from 92% to 77% even on gpt-5.4, with paired McNemar p < 0.005, framing the bottleneck as memory maintenance rather than comprehension.

The authors further report that increasing conversation length by 24x degrades performance from 68% to 28%, while proportional memory expansion yields no detectable recovery in n = 25. They release Supersede as a trainable environment with a programmatic reward for current-value answers and show a single GRPO run on Qwen2.5-3B improves held-out real conversational supersession accuracy from 9.0% to 16.7%.

1. Introduction

The introduction positions supersession as a central long-horizon agent problem: facts are introduced, later revised, and must be overwritten in memory. The paper names the lost accuracy under bounded self-maintained memory the supersession gap and structures the contribution around four questions: whether the failure exists, whether model scale fixes it, whether memory size fixes it, and whether training can reduce it.

The authors claim five contributions: an isolation result separating memory maintenance from reading comprehension, a frontier-model confirmation, a scale-vs-size ablation, an open verifiers/prime-rl environment, and a proof-of-mechanism training result. The introduction is well aligned with practical agent-memory design because it focuses on state updates rather than static recall.

2. Related Work

The paper situates itself among long-term memory benchmarks such as LoCoMo, LongMemEval, MemoryArena, MemoryAgentBench, MemBench, Memora/FAMA, and temporal-conflict QA. The key distinction is that those works mainly evaluate memory or forgetting behavior, while Supersede attempts to make supersession-correctness a training signal.

For memory-system and RL-for-memory work, the authors contrast Supersede against Mem0, MemAgent, LongRLVR, AgeMem, Memory-T1, and MemPO. Their claimed differentiator is strict no-re-feeding of raw history plus a reward directly tied to which version of a fact is current, rather than final-answer success, evidence relevance, or memory task-sufficiency. The section also references closed deployed memory systems from major labs, but those comparisons rely on public product claims rather than independently audited methodology.

3. The Supersede Environment

A task consists of multiple sessions followed by a query about the current value of a changed fact. The agent updates a bounded notes memory after each session; raw sessions are never re-fed. This design forces the memory field to carry all relevant state and makes stale or missing memory updates directly visible at the final answer.

The primary reward is r_cur = 1 when the final answer conveys the current value, scored by a programmatic matcher using normalization, gold variants, substring matching, and token-overlap fallback. When stale values are known, the environment can add r_stale = -1 for asserting superseded values, though reported runs optimize r_cur alone.

4. Experimental Setup

The authors first built a procedural synthetic generator but found frontier models score 100% when full history is in context, making templated supersession uninformative for diagnosis. They therefore use the LongMemEval knowledge-update subset for real conversational updates, while retaining synthetic timelines for controls and training curriculum.

The main diagnosis uses 78 oracle-split questions with about 2 evidence sessions per question, graded by a gpt-4.1-mini judge following LongMemEval protocol and cross-checked against the programmatic matcher. The scale study uses a longer split with about 48 sessions and about 122k tokens per question, and training uses Qwen2.5-3B-Instruct with GRPO, LoRA rank 32, learning rate 1e-5, batch 32, group size 8, and 4x A10G GPUs on 2000 synthetic episodes.

5.1 Bounded memory degrades supersession

Table 1 and Figure 2 provide the main gap result. gpt-4.1-mini drops from 82% full-context to 63% bounded-memory accuracy, with p = 0.0035; gpt-4.1 drops from 91% to 64%; gpt-5.4 drops from 92% to 77%, with p = 0.0033. Full-context accuracy rises and saturates with stronger models, but bounded-memory accuracy lags.

The authors interpret this as evidence that memory maintenance, not comprehension, is the bottleneck. Qualitative errors are dominated by current facts being compressed away or not overwritten, producing answers such as “you haven’t mentioned any” or “no information” when the relevant updated fact appeared earlier but did not survive in notes.

5.2 It is scale, not memory size

The scale study tests whether the bounded memory budget of 300 characters is simply too small. With gpt-4.1-mini on n = 25, moving from the oracle split at about 2 sessions to the longer s split at about 48 sessions drops accuracy from 68% to 28% at the same 300-character memory, with paired McNemar p = 0.002.

Increasing memory proportionally for the long split leaves accuracy at 28%. The authors note that larger memory changed all 25 answers but helped and hurt in equal measure, giving McNemar b = c = 4. This supports the claim that longer histories make update maintenance harder beyond simple compression ratio, although the small n limits precision.

5.3 Training closes the gap

On procedural training episodes, GRPO reward rises from 0.66 to 0.97, then the run self-terminates at step 175 after zero-advantage batches because nearly every sampled rollout in a group succeeds. The authors treat this as saturation of the easy synthetic curriculum rather than a failure of the method.

On held-out real LongMemEval oracle items, the same Qwen2.5-3B policy improves from 7/78 correct (9.0%) to 13/78 correct (16.7%). The checkpoint curve is flat through steps 50 and 100, then rises at steps 150 and 175, which supports a real training effect under the fixed harness and matcher, but statistical significance is not established because it is a single run.

6. Discussion

The discussion reframes supersession as a memory-policy problem. Larger models can read updated context well, but under bounded state they still discard or fail to overwrite facts that later matter. This is exactly the regime of persistent memory systems that consolidate user profiles without replaying all prior sessions.

The authors argue that two intuitive fixes—larger models and larger memory—do not close the gap, while a trained currency-preserving policy moves the metric. The conclusion is plausible, but the evidence supports “trainable signal exists” more strongly than “training is the definitive solution.”

7. Limitations

The authors clearly state that the training result is proof-of-mechanism, not a finished policy: one small model, one run, modest absolute gain, low final accuracy, and a synthetic curriculum that saturates. They also acknowledge that harder, longer, more implicit training episodes are needed to determine whether the curve can continue.

The diagnosis has additional caveats: the scale study has n = 25, added sessions are distractors rather than necessarily more updates to the tracked fact, Section 5.1 uses an LLM judge while later sections use the matcher, and the matcher is lenient on surface form. These limitations are material and should remain near any citation of the training result.

8. Conclusion

The conclusion states that agents fail at supersession because they cannot maintain changed facts under bounded memory, not because they cannot read updates in full context. The gap is significant on the benchmark, worsens with longer conversation history, and is not eliminated by model or memory scaling in the reported experiments.

The closing claim is that Supersede demonstrates a trainable route toward more current agent memory. The strongest defensible reading is that the environment provides a useful diagnosis and a promising reward design; the policy result is an early signal requiring replication, harder curricula, and broader model/task evaluation.

Appendix A: Reward matcher

The matcher lowercases text, replaces punctuation with spaces, collapses whitespace, creates acceptable gold variants by splitting on connectives and separators, and checks whether any gold variant appears as a normalized substring in the answer. If not, a token-overlap fallback credits answers with overlap greater than 0.6.

The same matcher can score stale values when known and apply a penalty. This design is pragmatic and judge-free, but it may credit near misses or partial answers, so absolute accuracies are matcher-defined rather than necessarily human-equivalent.

Appendix B: Training details

Training uses procedurally generated bounded-memory episodes with 6-8 sessions, one fact introduced and later superseded, and the update buried among distractors. Evaluation uses the untouched real LongMemEval oracle set, making the train/test distinction conceptually clean.

The full GRPO configuration is listed in Table 4: Qwen2.5-3B-Instruct, LoRA rank 32 with alpha 64 and dropout 0, target modules q/k/v/o/gate/up/down projections, no KL penalty, greedy evaluation, answer limit of 64 tokens, and self-halt at step 175 out of 200 maximum.

Appendix C: Example episodes

The examples show simple synthetic timelines: a user first lives in Chicago and later moves to Atlanta, or first drives a Mazda, then a Kia, then a Lexus. The reward requires the final current value, not the superseded values.

These examples clarify the environment semantics but also reveal why the synthetic curriculum may be easier than real conversational memory: updates are explicit, short, and semantically clean, even if buried among distractors.

Workflow — Supersede environment

Inputs:
  Multi-session conversation with at least one changed fact.
  Final query asking for the current value.
  Bounded notes-memory budget B.
Process / decision rules:
  1. Present one session at a time.
  2. Agent rewrites notes memory after each session.
  3. Do not re-feed raw prior sessions.
  4. After final session, answer query from memory alone.
Outputs:
  Final answer plus programmatic current-value reward.
Failure modes:
  Current fact compressed away; stale value retained; update not recognized; notes polluted by distractors; larger memory induces distraction rather than recovery.
Human review:
  Needed for matcher audit, edge cases, partial-value answers, and natural-language equivalence.
Governance:
  Track prompt, memory budget, session split, matcher version, stale-value annotations, checkpoint, and deterministic decoding settings.

Algorithm — Reward matcher

Inputs: model answer a; gold current value g; optional superseded values.
Normalize: lowercase; replace punctuation with spaces; collapse whitespace.
Gold variants: split g on "or", "and", "/", ";", and comma; keep variants length >= 2.
Match: reward if any normalized gold variant occurs as substring of a.
Fallback: reward if token overlap with a gold variant exceeds 0.6.
Current-value reward: r_cur = 1[match].
Stale penalty: if stale values are known, match answer against stale values and apply r_stale.
Reported optimization: uses r_cur alone; stale penalty only appears in environment ablation.
Appraisal: deterministic and trainable, but permissive enough that absolute accuracy needs manual audit.

Implementation and practice takeaways

Build

Use a no-re-feed memory harness as a regression test for any persistent memory/RAG agent. Full-context accuracy should be treated as an upper bound, not as evidence that memory maintenance works.

Measure

Track current-value accuracy, stale-value assertion rate, missing-answer rate, and memory-note overwrite behavior separately. Pair questions across conditions when testing memory budget or policy changes.

Reward design

A deterministic current-value matcher is a useful starting point, but maintain a manual audit set for near-miss answers, partial quantities, aliases, and multi-value facts.

Do not overclaim

Do not claim larger context windows, larger summary notes, or stronger models solve temporal memory. This paper suggests they help incompletely and inconsistently.

Next experiments

Run multi-seed training, harder implicit synthetic updates, real update logs, multiple open models, memory-store baselines, retrieval baselines, and calibration of matcher vs human labels.

Use in a paper library

Index under agent memory, temporal consistency, evaluation harnesses, deterministic rewards, and post-training environments. Preserve Figures 1-4 and Tables 1-4 as the reusable evidence core.

Best use: Treat Supersede as a design pattern for testing whether an agent can keep memory current under explicit update pressure. The artifact is most useful for building local test fixtures, not for selecting a production memory product.
Do not use for: Claims that deployed LLM memory systems are solved or unsafe; claims that GRPO generally fixes long-term memory; clinical, regulatory, or patient-care decisions.
