## Targeted verifier and long-context findings

- MTE pairwise disagreement rises from 40.6% below 8K to 64.0% at 32–64K; OPD preference gap changes from +0.35 to -0.37.
- HRR pairwise disagreement rises from 35.2% to 60.2%; OPD preference gap changes from +0.65 to -0.35.
- GC-OPD requires a response-level verifier that can return binary or graded rewards and compares it with trajectory-level OPD only after separate within-group normalization.
- If verifier reward or trajectory OPD score lacks within-group variation, the correction is zero and the group falls back to vanilla OPD.
- RACA uses relative OPD advantage only as an allocation signal; the paper explicitly states it is not token correctness or causal importance.
- The completed implementation uses beta=0.10, tau_G=tau_T=1e-6, and final advantage clipping to [-10,10].
