# D^2ACCI diagnostic-stage taxonomy and DCR design

Source: D^2ACCI: A Dual-Loop Diagnostic Protocol for Evidence-Preserving Agent Memory  
Identifier: arXiv:2608.17756v1  
Submitted: 2026-08-18  
Primary category: cs.AI

## Diagnostic-stage model

D^2ACCI treats a memory system as a sequence of inspectable stages. The runtime trace keeps the evidence needed to determine where a failure first becomes actionable.

| Trace element | What it records | Minimum useful evidence described in the paper |
|---|---|---|
| Raw evidence | Information in the interaction history | Source-turn or source-memory identifiers |
| Stored memory | What ingestion wrote to memory | Memory identifiers and stored representation |
| Retrieval | Candidate memories returned for the query | Top-k items and scores |
| Filtering or reranking | Items retained, removed, or constrained | Filter decisions |
| Context assembly | Evidence actually packed into the model context | Final packed context, including dropped items when available |
| Constraint handling | Forget and update restrictions | Constraint identifiers and guard decisions |
| Generation | Final answer and evaluation | Output plus judge metadata |

The paper's root-cause taxonomy uses the earliest actionable failure stage:

1. ingestion miss
2. retrieval miss
3. context-assembly error
4. constraint error
5. generation error
6. component hurt
7. unresolved ambiguity

A separate PersonaMem-V2 audit of 2,140 wrong cases assigned 57.1% to generation or option scoring, 29.8% to constraint handling, 13.0% to retrieval misses, and 0.1% to ingestion misses. In that audit, 87% of failures were beyond retrieval, which changes where engineering effort should go.

## DCR metric

Diagnostic Coverage Rate is an observability measure, not an accuracy metric.

For a failure or discordance set F, stage set S, trace d_i, and per-stage actionability predicate A(d_i, s):

```text
C(d_i) = number of stages in S with actionable trace evidence
DCR_tau(F; S) = (1 / |F|) * sum_i 1[C(d_i) >= tau]
```

A stage counts as actionable only when its schema-required evidence is present. The implementation described in the paper validates these fields rather than accepting free-form logs.

The default gate uses `DCR@3` with `rho_min = 0.90`. Sensitivity is also reported at `DCR@1`, `DCR@5`, and `DCR@6`.

The paper reports pair-level DCR@3 of 99.21% for LoCoMo No-BM25/RRF discordances, 99.47% for LoCoMo No-Supplement cases, 98.63% for LongMemEval No-Session cases, and 100% for PersonaMem-V2 No-Forget-Guard cases. A 110-example LoCoMo result-only check scored 0% at DCR@3.

## Gate order

The outer loop applies the checks in a fixed order:

```text
1. Incomplete report -> Feature-Flag
2. Statistically significant harm -> Reject
3. DCR below minimum -> Feature-Flag
4. Paired evidence inconclusive -> Feature-Flag
5. Protected-slice regression beyond tolerance -> Accept with Monitor
6. Otherwise -> Accept
7. Archive the decision, rationale, checks, monitors, and prior evidence
```

The order matters. A candidate with a favorable headline metric can remain feature-flagged if the trace is too weak to localize failures, or can be accepted only with a monitor if a protected slice regresses.

## Reusable design patterns

For an agent or literature pipeline, the most reusable parts are concrete:

- Pair candidate and baseline runs on stable sample IDs.
- Define protected slices before looking at candidate results.
- Keep null findings and rejected changes in the artifact history.
- Emit typed stage traces with IDs, scores, decisions, and packed-context records.
- Separate task accuracy from diagnostic coverage.
- Make promotion rules deterministic and replayable from saved artifacts.
- Keep a queue of discordant and failed cases for root-cause review.

## Limits

The evidence comes from one memory stack tested on three public benchmarks plus a small external compatibility slice. Some cross-benchmark ablations were incomplete. The paper also identifies online evaluation, cross-stack comparisons, and automated trace verification as future work.
