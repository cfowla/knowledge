## Focused triage findings

### Environment-generation loop

A single shared LLM alternates between Environment Designer and Reasoning Agent roles. The designer emits executable Gym-style Python environments plus privileged hints. The agent plays each environment with and without the hint. The return gap supplies hint-based regret for the designer; task completion rewards the agent. Corpus grounding supplies breadth, while environment memory tracks which generated environments remain useful at the learner's current frontier.

### Held-out evaluation

The games experiments retrain two fixed-environment baselines from the same base models for the same 400-iteration budget, and all eight evaluation benchmarks are held out from training. At Qwen3-30B-A3B scale, SPADE reaches an eight-benchmark mean of 58.3, compared with 50.2 for the untrained base and 53.0 for fixed-environment RLVE. The tool-use setting improves within-model performance on BFCL v4 multi-turn, tau2-bench, and ACEBench-Agent, but published external-system rows use non-matched protocols.
