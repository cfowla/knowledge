## Extraction / schema limitations

1. The LiteratureAtom model is primarily shaped for conventional primary-study populations/exposures/outcomes. AI/ML quantitative results were mapped conservatively: model/configuration as exposure, evaluation split/task as population context, and the reported metric as outcome.
2. Figure 7 contains plotted rather than tabulated loss values. The atom set preserves the authors' figure-level comparison qualitatively rather than inventing exact point estimates from the graph.
3. The paper does not present a dedicated funding or conflict-of-interest statement in the primary PDF. Absence was not converted into reported evidence.
4. The strongest brain claims are not supported by direct neural recordings or biological intervention experiments in this paper; they remain theoretical/mechanistic interpretations.
5. Appendix E is a didactic code listing and explicitly leaves RoPE implementation to the user; the code was not executed as part of source appraisal.
