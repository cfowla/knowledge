One-page synthesis

Core thesis: RAG transparency should not be reduced to citations. ProvenAI separates three layers—answer correctness, citation fidelity against gold supporting evidence, and resource influence under leave-one-resource-out ablation—because the cited documents and the documents that behaviorally shape the output can diverge.

ProvenAI is not presented as a stronger QA model. It is an audit harness for retrieval-grounded question answering. The implemented pipeline normalizes HotpotQA distractor records, builds a FAISS retrieval index over a deduplicated corpus, generates citation-aware answers, audits citations against gold supporting titles, estimates document influence through ablation, aggregates validation metrics, and exposes results through a Streamlit/MCP trace interface.

The paper’s empirical anchor is mixed. It evaluates 7,405 HotpotQA validation examples and reports 53.53% answer accuracy with 71.55% mean citation-fidelity score, supporting the claim that answer accuracy and citation alignment are separable. However, the strongest “citation-influence gap” result rests on a targeted case study rather than full-validation ablation, because leave-one-resource-out influence was disabled in the full run for cost. The conceptual framing is high-value for RAG evaluator design, but the evidence base remains early.

Section-by-section condensation

Abstract

The abstract frames the problem: citations in generated answers are not proof that the cited source meaningfully shaped the output. ProvenAI decomposes transparency into answer correctness, citation fidelity, and per-document influence, then evaluates a seven-stage pipeline on HotpotQA distractor with 7,405 validation examples and a canonical corpus of 509,300 passages.

Reported outcomes are 53.53% answer accuracy and 71.55% mean citation-fidelity score. The abstract foregrounds a worked example in which citation audit looks clean but influence analysis finds one weakly influential cited source and seven uncited influential sources, formalizing this as a “citation-influence gap.”

1. Introduction

The introduction argues that multi-hop RAG intensifies evidence-transparency problems because correct answers may depend on several retrieved documents. A model can cite only a subset of retrieved passages while still being shaped by the uncited remainder, so citation lists only answer what the model claims to have used, not whether those sources match gold evidence or caused the generated output.

The paper positions ProvenAI as infrastructure for measuring evidence propagation, not as a new retriever or generator. Its stated contributions are a three-layer transparency decomposition, reproducible pipeline artifacts, characterization of the citation-influence gap, formal connection between a surface proxy and KL-divergence influence, and linkage to causal mediation, database provenance, cryptographic provenance, and autonomous scientific discovery.

2. Related Work

The related work situates ProvenAI among RAG foundations, multi-hop QA benchmarks, citation-verifiability metrics, context attribution, causal mediation, database provenance, and MCP-style tool/resource access. The key distinction is that ProvenAI asks whether removing a retrieved document changes the answer or citation pattern after the document has been retrieved and possibly cited.

The closest conceptual neighbors are attribution and citation-evaluation methods such as ALCE, MIRAGE, ContextCite, SelfCite, FActScore, and RAGAS. ProvenAI uses a document-level ablation intuition and categorical verdicts rather than training a citation model or directly using probability-aware attribution.

3. Problem Formulation

The formulation defines a question q, retrieved resources R = {r1...rk}, generated answer a, citation set C ⊆ R, gold answer a*, and gold supporting titles G. It evaluates answer correctness with normalized string matching, citation fidelity by comparing cited titles to gold supporting titles, and resource influence by checking whether removing a retrieved resource changes the answer or citation set.

Citation fidelity is measured with token-set Jaccard similarity over document titles at a fixed threshold. Influence is ideally defined as a KL divergence between full-context and ablated-context output distributions, but the implementation uses a surface proxy combining answer-token Jaccard shift and citation-set Jaccard shift. Each retrieved document is assigned one of four labels: USED, HALLUCINATED CITATION, UNCITED INFLUENTIAL, or LOW INFLUENCE.

4. System Design

The system is organized into seven stages: data normalization, retrieval-index construction, citation-aware answer generation, citation-fidelity audit, document-influence estimation, aggregate evaluation, and interactive inspection. The modular design is useful: each phase writes disk artifacts so downstream phases can be rerun, audited, or swapped without recomputing everything.

The data layer converts HotpotQA distractor examples into stable JSONL records, creates a deterministic 250-example development subset, deduplicates evidence rows, embeds passages with all-MiniLM-L6-v2, indexes them with FAISS inner-product search, and mirrors records in SQLite. The generation layer uses Qwen2.5-3B-Instruct through an MLX path, asks for citation-tagged output, repairs parsing failures, and records MCP trace artifacts for replayable resource access.

5. Experimental Setup

The evaluation uses the full HotpotQA distractor validation split. The paper reports dataset and runtime configuration in detail because retrieval depth, generation model, prompt document limits, citation threshold, and model scale can materially affect answer accuracy and audit behavior.

Answer correctness is evaluated with lightweight normalization: citation tags are stripped, strings are lowercased and trimmed, and yes/no questions use prefix matching. The authors explicitly caution that this scoring is for internal diagnostics and should not be directly compared with official HotpotQA leaderboard scores.

6. Results

Aggregate validation shows 53.53% answer accuracy and 71.55% citation fidelity over 7,405 examples. The 18-point spread supports the paper’s central idea that answer correctness and evidence alignment can decouple: a system may cite the right titles even when answer generation fails, or answer correctly despite degraded citation alignment.

The case study asks whether Scott Derrickson and Ed Wood were of the same nationality. The model answers correctly and cites the two gold supporting titles, producing perfect citation fidelity. Leave-one-out ablation across 10 retrieved documents then finds 1 USED document, 1 HALLUCINATED CITATION, 7 UNCITED INFLUENTIAL documents, and 1 LOW-INFLUENCE document, demonstrating that the visible citation set can diverge from the output’s sensitivity profile.

7. From Measurement to Provenance-Native Reasoning

This section extends the framework from measurement to provenance-native reasoning. The paper argues that cryptographic provenance can validate which resources were retrieved and signed, but this still does not prove that the cited subset was what shaped the generated conclusion. A system can be cryptographically sound at module boundaries and still be behaviorally influenced by uncited co-retrieved context.

The proposed audit record includes four artifacts per generated claim: a retrieval manifest, a citation manifest, a verdict assignment over retrieved resources, and a proxy-to-target statement explaining when influence numbers are interpretable. This makes the paper most relevant to RAG observability, scientific-agent audit trails, and secure evidence pipelines rather than leaderboard QA performance.

8. Discussion and Limitations

The discussion states the central caution directly: citations indicate claimed use, not confirmed influence. The three-layer decomposition exposes cases that aggregate accuracy cannot distinguish, including correct answers with poor citation fidelity and clean citation audits with diffuse or uncited influence.

The main limitations are substantial: the MLX backend does not expose per-token probabilities, so influence is not measured with the KL target; the implemented model is only Qwen2.5-3B-Instruct; citation audit is title-level rather than claim/sentence-level entailment; all aggregate results come from HotpotQA distractor; and rich audit artifacts may increase user overconfidence if presented as guarantees rather than diagnostic indicators.

9. Conclusion

The conclusion restates that transparency in retrieval-grounded QA is layered. Answer correctness, citation lists, and resource-influence profiles can disagree, and ProvenAI offers a reproducible framework for making those disagreements visible.

The strongest contribution is not the raw performance numbers; it is the audit pattern and vocabulary. The paper gives a useful decomposition for RAG system evaluation while acknowledging that stronger probability-aware influence measurement, larger models, sentence-level evidence checks, and additional benchmarks are needed before broader claims are warranted.

Appendices

Appendix A proves the one-sided relationship between positive answer-surface change and positive KL divergence under near-deterministic decoding, while also showing that the reverse implication fails. The example given is a probability shift that leaves the greedy argmax unchanged, creating nonzero KL divergence with zero observed answer change.

Appendix B lists reproducibility commands for the pipeline, and Appendices C–E describe dashboard screenshots, additional experimental constraints, and MCP traceability. The appendices are practically important because they clarify that current influence claims should be framed as answer-and-citation sensitivity rather than probability-level causal influence.

Method and measurement scaffold

Core objects

QUESTION AND EVIDENCE SETUP

q       = user/question benchmark item
R       = retrieved resource set {r1, ..., rk}
a       = generated textual answer
C       = citation set emitted by the generator, where C ⊆ R
a*      = gold answer
G       = gold supporting document titles supplied by HotpotQA

THREE INDEPENDENT LAYERS

1. Answer correctness
   - Does normalized generated answer a match gold answer a*?

2. Citation fidelity
   - Do cited titles C match gold supporting titles G?

3. Resource influence
   - Does removing resource ri from context change the answer or citation set?

Citation fidelity equations

CITATION FIDELITY

TC = cited titles
TG = gold supporting titles
sim(t, g) = token-set Jaccard similarity
τ = fixed matching threshold; reported exact τ = 1 and semantic τ = 0.34

Precision proxy:
Pτ = (1 / |TC|) Σ[t ∈ TC] 1(max[g ∈ TG] sim(t, g) ≥ τ)

Recall proxy:
Rτ = (1 / |TG|) Σ[g ∈ TG] 1(max[t ∈ TC] sim(t, g) ≥ τ)

Fidelity score:
Fτ = 2PτRτ / (Pτ + Rτ)

Resource influence target and implemented proxy

CONCEPTUAL TARGET

InfluenceKL(ri) = DKL( p(· | q, R) || p(· | q, R \ {ri}) )

IMPLEMENTED SURFACE PROXY

a-i = regenerated answer after removing ri
C-i = regenerated citation set after removing ri

Answer shift:
Δa(ri) = 1 - Jaccard(tok(a), tok(a-i))

Citation shift:
Δc(ri) = 1 - |C ∩ C-i| / |C ∪ C-i|

Combined influence proxy:
φ(ri) = 0.8Δa(ri) + 0.2Δc(ri)

Interpretation:
- Positive surface change can witness a nontrivial KL shift under near-deterministic decoding.
- Zero surface change does not prove zero influence, because probability mass can shift without changing the greedy output.

Verdict assignment

VERDICT LABELS FOR EACH RETRIEVED RESOURCE ri

Threshold:
θ = max(median({φ(ri)}), θfloor)

Citation indicator + influence proxy:

1. USED
   Condition: ri ∈ C and φ(ri) ≥ θ
   Meaning: cited and behaviorally influential under the proxy.

2. HALLUCINATED CITATION
   Condition: ri ∈ C and φ(ri) < θ
   Meaning: cited but weakly influential under the proxy.

3. UNCITED INFLUENTIAL
   Condition: ri ∉ C and φ(ri) ≥ θ
   Meaning: not cited, but answer/citation output changes when removed.

4. LOW INFLUENCE
   Condition: ri ∉ C and φ(ri) < θ
   Meaning: not cited and low observed sensitivity under the proxy.

Evaluation and appraisal

Verdict: Read first for RAG/provenance evaluator design; do not treat as mature empirical evidence for deployed RAG reliability. The paper is conceptually aligned with practical RAG harness work and provides useful instrumentation vocabulary, but its strongest behavioral influence claim is case-study level and the current proxy is intentionally weaker than the formal KL target.

Major strengths

  • Useful decomposition: separates answer correctness, citation fidelity, and influence instead of collapsing them into one trust signal.
  • Operational artifact design: uses staged saved outputs, per-example reports, summary JSON, dashboard inspection, and MCP trace records.
  • Clear diagnostic labels: USED, HALLUCINATED CITATION, UNCITED INFLUENTIAL, and LOW INFLUENCE map cleanly to reviewable RAG failure modes.
  • Honest formal limitation: explicitly states that the surface proxy is one-sided and can underestimate distributional influence.

Major limitations

  • Full-validation influence not measured: aggregate influence score is zero because ablation was disabled, so the main influence-gap phenomenon is illustrated by a targeted case report.
  • Title-level citation audit: matching document titles is weaker than verifying sentence-level support or claim-level entailment.
  • Surface proxy under-detects influence: unchanged greedy output does not imply unchanged distribution, and the implementation lacks token-level probabilities.
  • Small-model and benchmark constraints: Qwen2.5-3B-Instruct on HotpotQA distractor may not generalize to larger RAG systems, open-domain retrieval, clinical sources, or agentic workflows.
  • Thresholding is heuristic: adaptive median-plus-floor thresholding makes labels inspectable but not necessarily calibrated across examples or models.

Bottom-line interpretation

ProvenAI is best read as a RAG audit harness blueprint. Its most durable contribution is the insistence that citations, gold-evidence alignment, and behavioral influence are different audit layers. The design is directly reusable for evaluators that need to answer: what was retrieved, what was cited, what matched gold evidence, what changed the output when removed, and what should a reviewer inspect?

The empirical evidence is not yet strong enough to support broad claims about how often citation-influence gaps occur across real systems. To make the paper deployment-relevant, the next version would need probability-aware influence scoring, sentence/claim-level citation verification, larger and multiple generators, broader datasets, full-batch or sampled influence prevalence estimates, and stronger calibration of verdict thresholds.

Implementation and practice takeaways

Build-useful pattern
Separate retrieved, cited, gold-supported, and influential resources.

A RAG evaluator should not stop at citation rendering. It should preserve the full retrieved set, parsed citation set, gold or adjudicated support set, and a sensitivity score for each resource.

Highest-value addition
Add leave-one-resource-out sensitivity to selected examples.

Full ablation can be costly, but targeted ablation on failures, high-risk answers, or random validation samples can expose uncited influence without multiplying inference cost for every run.

Needed for rigor
Move from title matching to claim-level entailment.

For scientific or clinical use, matching source titles is insufficient. Each cited claim should be checked against exact passages or sentences, with unsupported claims surfaced separately.

Needed for causal attribution
Use logprob-capable backends.

If the goal is true distributional influence, use an inference backend that exposes token probabilities and compare the implemented proxy against KL/logprob attribution methods.

Operational caution
Display influence as diagnostic, not proof.

Audit dashboards can increase overconfidence. Labels like USED or LOW INFLUENCE should include caveats about proxy limits, benchmark scope, and threshold behavior.

Fit to local workflows
Relevant to deterministic RAG/agent harnesses.

The staged report pattern is compatible with local structured outputs, audit JSON, human review queues, and later HTML or Markdown reference-file generation.

Quality-control notes

Most important caveat: the paper’s key concept is useful even though the empirical demonstration is early. Do not overread the single worked ablation example as prevalence evidence.

What this source establishes

  • It establishes a clear measurement vocabulary for layered RAG transparency.
  • It demonstrates that answer accuracy and citation fidelity can diverge on HotpotQA under the reported setup.
  • It provides an example where clean citation audit and influence profile diverge.
  • It gives a practical staged architecture for generating reusable audit artifacts.

What this source does not establish

  • It does not establish the population prevalence of citation-influence gaps because full-validation ablation was disabled.
  • It does not prove sentence-level citation support or claim-level factuality.
  • It does not validate the approach across clinical, scientific-literature, enterprise, or open-web RAG settings.
  • It does not demonstrate that the dashboard improves reviewer decisions or reduces operational risk.
