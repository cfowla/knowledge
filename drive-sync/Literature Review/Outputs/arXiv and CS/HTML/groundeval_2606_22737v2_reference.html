One-page synthesis

Verdict: Read first for deterministic agent-evaluation architecture; do not treat as broadly validated benchmark evidence. The paper is directly relevant to agent/RAG evaluation, trace auditing, and regression gates for tools operating over private, time-bounded, access-controlled evidence.

Core thesis. GroundEval argues that stateful agents can be wrong even when their final answers are factually plausible or label-correct, because the answer may not be validly reachable under the actor’s time, access, subsystem, search-space, or causal constraints. The proposed alternative to prose-only LLM-as-judge is a deterministic contract that scores observable agent behavior: searches, fetches, citations, tool traces, timestamps, permissions, and structured final-answer fields.

Framework. The evaluation has three tracks. Perspective checks whether an actor could have known a fact at a time under role/subsystem access. Counterfactual checks whether a claimed causal relation is supported by configured event links and join conditions rather than topical or temporal proximity. Silence checks whether an agent searched the expected evidence space before claiming absence. Each run receives answer and trajectory scores, then a compliance-adjusted score penalizes actor-gate, subsystem, and horizon violations.

Evidence presented. The evaluation uses a synthetic OrgForge enterprise corpus with nine subsystems, 72 actors, eight roles, 22,530 events over 60 days, 25 causal link types, 19 silence pair types, and 96 generated questions. The tested model is DeepSeek-V4-Pro at temperature 0 in two conditions: tool mode and zero-shot no-artifact mode. The main result is not high absolute agent performance; it is the diagnostic gap between plausible final answers and invalid evidence paths, including a Silence example where prose-only LLM judges scored a wrong response 0.90 and 0.85 while GroundEval scored the answer 0.000 because the required artifact was never fetched.

Main limitation. The paper is compelling as a design pattern and failure taxonomy, but the empirical evidence is narrow: one synthetic corpus family, one evaluated model, no external domain replication, no human adjudication study of contract quality, no ablation of contract components, and limited reporting on code reproducibility or integration friction beyond adapter requirements.

Section condensation

Abstract

The abstract frames GroundEval as a deterministic alternative to LLM-as-judge for stateful agents that operate over real context. It targets evidence-path validity: what the agent searched, fetched, cited, and was allowed to access.

The central example establishes the paper’s diagnostic value: a plausible negative answer receives high prose-only judge scores, but a trace check shows the agent never retrieved the required artifact, producing a deterministic answer score of 0.000. The abstract identifies three tracks: Silence, Perspective, and Counterfactual.

1. Introduction

The introduction defines the problem as state governance rather than ordinary reasoning failure. A model can produce the correct label while using future evidence, inaccessible evidence, another user’s memory, an unsearched absence space, or unsupported causal evidence.

The paper contributes a task-contract model, three reusable tracks, dual answer/trajectory scoring, and deterministic scoring guarantees for observable behavior. The key concept is state-invalid correctness: an answer can be true but invalid because it was not reachable under the evaluation state.

2. Background and related work

The related-work section distinguishes GroundEval from LLM-as-judge methods such as MT-Bench, Chatbot Arena, and G-Eval; process-supervision work; trajectory/tool-use benchmarks; RAG attribution metrics; and long-term memory benchmarks. The argument is that these methods often assess preference, plausibility, tool mechanics, retrieval faithfulness, or memory recall without enforcing actor-specific time/access constraints.

This positioning is plausible but partly author-framed. The paper cites relevant benchmark and RAG evaluation work, but it does not empirically compare against state-aware alternatives beyond the prose-only judge demonstration.

3. Framework overview

GroundEval uses Observe Mode to run an agent under its native framework, record tools/evidence/final answer, and draft a task contract. A human reviews and corrects the contract, which then defines required checks, allowed evidence, temporal boundaries, access constraints, answer schemas, and scoring obligations.

The design separates domain state from scorer logic: event logs, artifact corpora, access policies, and evaluation configuration carry domain meaning. A validator checks for structural defects such as causal specs with no links, silence specs with empty search spaces, missing artifact IDs, or roles with no accessible subsystems.

4. Formal properties

The paper states three properties: answer scores are judge-independent functions of ground truth; trajectory scores are deterministic for identical traces and configurations; and the framework has bounded scope limited to evidence-path violations.

This section correctly narrows the claim. GroundEval does not score style, persuasion, creativity, subjective quality, or hidden chain-of-thought. It evaluates externally observable behavior only.

5. Evaluation tracks

Perspective checks whether an actor could have known a fact under time and role/subsystem constraints. Counterfactual checks cause-effect relationships using configured event types, maximum gaps, mechanism aliases, and join conditions. Silence checks whether absence claims are justified by coverage of declared search spaces.

The leakage controls are a major strength: the question prose generator is not given ground-truth labels, questions are rejected for answer-leaking strings or artifact identifiers, per-actor/per-event caps reduce shortcuts, and deterministic templates provide fallback when validation fails.

6. Scoring

GroundEval separates final-answer correctness from trajectory validity. Track-specific weighting reflects task intent: Perspective and Silence emphasize path validity, while Counterfactual weights answer and trajectory evenly.

The compliance-adjusted score multiplies the weighted score by (1 − v)^2, where v aggregates actor-gate, subsystem, and horizon violations. This makes governance violations a multiplicative penalty rather than a detail hidden inside an answer score.

7. Experimental setup

The evaluation uses an OrgForge-generated synthetic enterprise scenario: nine subsystems, 72 actors, eight roles, 22,530 events over 60 days, 25 causal link types, and 19 silence pair types. It generates 96 questions: 30 Perspective, 27 Counterfactual, and 39 Silence.

The tested model is DeepSeek-V4-Pro at temperature 0. Tool mode allows fetch/search calls with recorded violations; zero-shot no-artifact mode supplies only the question and no corpus access, functioning as an answer-score floor rather than a trajectory baseline.

8. Results

The worked examples are the strongest part of the paper. They show three qualitatively distinct errors: a Silence false absence caused by not fetching CONF-PROD-002; a Perspective permission failure where co-attendance is mistaken for subsystem access; and a Counterfactual failure where topical dissimilarity overrides a join-linked causal chain.

Aggregate gated results are low: answer scores are 0.214 for Perspective, 0.063 for Counterfactual, and 0.359 for Silence; trajectory scores are 0.637, 0.357, and 0.421, respectively. The overall compliance-adjusted score is 0.350. These numbers primarily demonstrate diagnostic visibility, not mature agent performance.

9. Discussion

The discussion argues that contract authoring scales with the observed operating surface rather than manual specification. The framework can draft contracts from observed runs, then validation and human review prevent structurally unusable drafts from becoming scoring artifacts.

Integration depends on framework adapters. The paper reports direct CrewAI support and Microsoft Agent Framework capture through OpenTelemetry spans. For unsupported frameworks, an adapter must record observed runs without gating or replacing tool results.

10. Limitations

The limitations are material and appropriately stated. GroundEval requires an adapter, and it only captures evidence exposed through instrumented tool calls. Evidence embedded in prompts before runtime, or used outside the adapter’s visibility, cannot be evaluated.

Draft quality also depends on the observed run. A single happy-path run may fail to expose subsystems, preconditions, or checks that should appear in the contract; the human reviewer must notice and add them. This is a central operational risk.

11. Conclusion

The conclusion restates the main claim: for stateful agents, the evidence path is part of the answer. A response that is true but unreachable under access, temporal, causal, or search-space constraints is state-invalid.

The paper’s strongest future-work need is not another prose argument against LLM judges; it is broader replicated evaluation, contract-quality measurement, adapter coverage, and reproducible code-level evidence.

Implementation and practice takeaways

Build-useful idea

For any agent that answers from private or time-bounded context, store a machine-checkable task contract beside the test: allowed actor, as-of time, accessible subsystems, required search spaces, expected structured answer fields, and valid evidence artifacts.

Regression gate

Use answer score and trajectory score separately. A correct answer with a bad evidence path should fail a governance gate even when the final prose looks right.

Adapter requirement

This approach needs trace observability. Agents that receive hidden prompt context, use uninstrumented retrieval, or operate through black-box tools cannot be reliably evaluated without additional instrumentation.

Contract-review burden

Do not rely on a single observed run to draft contracts. Use representative workflows and review for missing subsystems, absence spaces, causal joins, and role/time boundaries.

Do not overclaim

Do not describe GroundEval as a universal replacement for LLM-as-judge. It replaces judge scoring only for state-validity failures that can be expressed in a contract and observed in a trace.

Do not use for

Do not use this evidence alone to select a production benchmark, validate an agent safety program, or compare general model quality across unrelated tasks.

Concrete local use cases

  • RAG audit: Require every negative answer to cover declared repositories before crediting absence.
  • Clinical/enterprise document agent: Encode role, patient/document scope, timestamp, and source system into test contracts.
  • Scientific paper triage agent: Penalize claims based on abstracts only when methods/results/figures were required by the task contract.
  • Tool-use harness: Track searches and fetches as first-class scoring objects, not logs only used for debugging.

What would make this paper stronger

  • Run multiple agent models and multiple frameworks, not one model under one synthetic setup.
  • Report variance across generated corpora and random seeds.
  • Add ablations for each track component, compliance exponent, and contract validation stage.
  • Benchmark against existing trajectory/RAG evaluators on matched state-validity tasks.
  • Audit the released code with reproduction instructions, fixtures, and expected outputs.
  • Evaluate human contract-author agreement and reviewer workload.
