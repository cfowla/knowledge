## Primary-literature schema limitation

The governing LiteratureAtom MVP is explicitly designed for **primary literature**, while this publication is a narrative review / consensus-style chapter. The extraction therefore uses the following guardrails:

- source-level synthesis statements are tagged `secondary_source`;
- numerical results that the review attributes to cited studies are additionally tagged `secondary_reported_result`;
- those numerical atoms remain anchored to this review and are **not** represented as if this chapter enrolled the underlying participants or generated the results;
- appraisal statements were not converted into reported-data atoms;
- missing study-level details were not invented to satisfy context fields.

This is a schema-fit limitation, not a structural-validation failure.

## Extraction limitations

- The PDF is OCR-derived and contains occasional character-recognition artifacts in parsed text. Main assertions, tables, and figures were cross-checked against rendered PDF pages.
- No external sources were used to verify current clinical practice, modern guideline alignment, present assay standards, or historical bibliographic details beyond what is available in the source PDF metadata/text.
- The source does not report a reproducible systematic-review search, study-selection method, or formal risk-of-bias process; this is handled in SEA appraisal rather than encoded as a reported primary-study method.
- The review contains many underlying study citations. Only source-supported, independently useful assertions were atomized; the bibliography itself was not treated as a set of primary-study atoms.
