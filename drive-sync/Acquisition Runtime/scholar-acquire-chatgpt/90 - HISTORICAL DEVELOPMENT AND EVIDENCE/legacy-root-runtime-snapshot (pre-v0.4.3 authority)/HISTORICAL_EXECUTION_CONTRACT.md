# Fail-Closed Scholarly Acquisition Execution Contract

This contract is normative for Acquisition Runtime use.

- No scholarly acquisition begins until package integrity is verified.
- No runtime evidence means no valid runtime execution.
- Python is the controller; external tools are adapters.
- Every external response must correspond to an emitted request and ingest capability token.
- `BLOCKED` is not `EXHAUSTED`.
- Search-engine absence is not provider exhaustion.
- A validated JATS payload is a full-text acquisition even when PDF transport is unavailable, subject to the active acquisition policy.
- Runtime-generated manifests and terminal outcomes outrank assistant-written summaries.
- All successful payloads retain SHA-256 provenance.
- Sci-Hub and access-control circumvention are forbidden.
