An **installable wheel** (`.whl`) is just Python’s packaged installation format—roughly the Python equivalent of an installer/archive. You would use it on a normal machine with:

```bash id="lpnbwh"
pip install scholar_acquire_chatgpt-0.2.0-py3-none-any.whl
```
